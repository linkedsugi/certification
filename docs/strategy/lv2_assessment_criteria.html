Lv.2 Creator 심사: 3개 영역, 각 영역 통과 필수

영역 1. 기능 동작 (Does it work?)

앱 실행

정상 구동

URL 접속 → 메인 기능 작동 확인. 빈 화면, 에러 = 즉시 탈락

핵심 플로우

입력→처리→출력

사용자가 입력하면 AI가 처리하고 결과가 나오는 기본 흐름 완성

에러 처리

기본 대응

빈 입력, 이상 입력 시 앱이 죽지 않고 안내 메시지 표시

영역 2. 도메인 가치 (Does it solve a real problem?)

문제 정의

명확한 타겟

"누구의, 어떤 문제를 해결하는가"를 한 문장으로 설명 가능

도메인 전문성

전문가 관점 반영

범용 AI 대비 도메인 지식이 녹아든 차별화 포인트 존재

실용성

실제 사용 가능

데모용이 아닌, 현업에서 반복 사용할 수 있는 수준

영역 3. 사용자 경험 (Can someone actually use it?)

첫 사용

30초 내 이해

설명서 없이 화면만 보고 무엇을 해야 하는지 파악 가능

인터페이스

기본 완성도

레이아웃 깨짐 없음. 버튼·입력창의 기본 정렬과 가독성 확보

결과 품질

AI 출력 적절

AI 응답이 도메인에 맞고, 환각이 치명적이지 않은 수준

통과 → Lv.2 인증 + AppCanvas 등록 권한

3개 영역 모두 기준 충족 시 Lv.2 Creator 인증 발급. AppCanvas Seed 크리에이터 자격 부여. 앱을 다듬어 정식 등록 가능.

미달 → 피드백 + 재심사 1회

미달 영역에 대한 구체적 피드백 제공. 2주 내 보완 후 1회 재심사 기회. 재심사 미통과 시 Lv.1 유지, 다음 기수에서 재도전.

심사 방식: 교육 마지막 날 "데모데이"에서 발표 + 실시간 시연. 심사위원은 MindCanvas 내부 심사관 1인 + 해당 도메인 교수/전문가 1인. 심사는 체크리스트 기반 (주관 배제). 소요 시간: 앱당 10~15분.
